ISSUE ENCOUNTERED AND FIX
-------------------------
Issue:
  First build printed this warning:
  "Warning: Next.js ignored package-lock.json in C:\Users\hfale because it
   is outside the current Git repository ... To use this directory, set
   `turbopack.root` in your Next.js config."

Root cause:
  Turbopack auto-detected a package-lock.json in the parent user directory
  (C:\Users\hfale) while resolving the workspace root. That made the
  detected root ambiguous and outside the project.

Fix:
  Added an explicit Turbopack root in next.config.ts:
      turbopack: { root: process.cwd(), ... }
  Rebuilt with bun run build. The warning is gone and the build still
  completes successfully.

Files changed for the fix:
  - next.config.ts
